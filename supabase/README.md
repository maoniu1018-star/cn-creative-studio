# CN Booking Studio｜Supabase 後端設定

這個資料夾提供多店家預約平台的資料庫起始結構。

## 建立方式
1. 建立 Supabase 專案。
2. 開啟左側 SQL Editor，新增查詢。
3. 複製並執行 `schema.sql` 全部內容。
4. 在 Authentication 啟用 Email 登入，並先註冊平台管理者帳號。
5. 暫時不要把任何 service_role 金鑰放進網站或 GitHub。

## 目前資料表
- businesses：店家基本資料與公開網址代稱
- business_members：店家與登入帳號的關係及角色
- services：店家服務項目
- bookings：預約資料及狀態

## 權限設計
- 未登入顧客只能讀取營業中的店家與服務項目。
- 未登入顧客可以新增待確認預約，但不能讀取任何預約清單或客戶個資。
- 登入店家成員只能管理自己所屬店家的資料。
- 同一店家的同一日期與開始時間，不允許同時存在兩筆待確認／已確認預約。

## 尚未完成
這是資料庫底層起始版本，尚未連接前台。正式開放前仍需完成登入頁、店家建立流程、店家管理權限驗證、可預約時段計算、營業時間／休假設定、通知與備份測試。
